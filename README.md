## 🧭 О себе

Инженер-энтузиаст с фокусом на **системном софте**, **терминальном UX** и **автоматизации рутины**. Люблю решения, которые работают быстро, предсказуемо и офлайн.

- ⚡ **Systems & TUI** — нативная производительность, чистый терминальный интерфейс
- 🤖 **AI-интеграции** — LLM в пользовательских сценариях (Groq), локальный STT (Whisper)
- 🛠️ **Developer tools** — платформы для повседневной работы разработчика
- 🐧 **Linux / dotfiles** — Niri, кастомизация окружения, воспроизводимые конфиги

> Открыт к интересным коллаборациям и open-source проектам.
